# グリーンアドバイザー 10時間集中コース

公益社団法人 日本家庭園芸普及協会「グリーンアドバイザー認定試験」対策の、自習用ウェブアプリ。
`index.html` をブラウザで開くだけで動く単一ファイル構成（外部依存なし・オフライン可）。

- **13章 / 104レッスン / 416問**、想定学習時間 約10.3時間
- 園芸店「みどりや」の店長・緑川さんと新人ハナちゃんの会話仕立て
- 本番形式の模擬試験（○×40問＋三肢択一40問／60分／合格ライン51問）
- まちがえた問題が自動で溜まる弱点ノート（2回連続正解で消える）
- 章別の正答率グラフ、スコアとコンボ、バッジ
- 進捗はブラウザに自動保存。保存コードで別端末へ持ち出しも可能

## 使い方

`index.html` をダブルクリックしてブラウザで開く。それだけ。

ローカルサーバーで開きたい場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000
```

## 試験の概要

| 項目 | 内容 |
| --- | --- |
| 形式 | CBT方式（全国のテストセンターで受験日時を予約） |
| 出題数 | ○×式 40問 ＋ 三肢択一式 40問 ＝ 80問 |
| 時間 | 60分 |
| 合格基準 | 80問中 51問以上正解（2025年度実績。年により変動） |
| 合格率 | おおむね 83〜86% |

最新の情報は[協会の公式ページ](https://www.kateiengei.or.jp/greenadviser/examination)で確認すること。

## 構成

```
index.html        ← 完成品。これ単体で動く（build.py が生成）
shell.html        ← UI のテンプレート。__DATA__ に教材データが差し込まれる
build.py          ← shell.html + content/*.json → index.html
content/
  ch01.json 〜 ch13.json   ← 章ごとの教材データ（本文・会話・表・クイズ）
```

## 教材を編集する

本文やクイズを直すときは `content/chNN.json` を編集して、ビルドし直す。

```bash
python3 build.py
```

`index.html` は生成物なので、直接編集しても次のビルドで上書きされる。

### 章データのスキーマ

```jsonc
{
  "id": 3,
  "title": "花を咲かせるスイッチ",
  "subtitle": "この章で何ができるようになるか",
  "minutes": 50,
  "goals": ["...", "...", "..."],
  "sections": [
    {
      "heading": "節タイトル",
      "dialogue": [ { "who": "客|ハナ|緑川", "text": "..." } ],
      "body": "<p>本文HTML（p, strong, em, ul, ol, li, h4, br, code のみ）</p>",
      "why": "この節の原理を1文で",
      "keypoints": ["試験に出る要点", "..."],
      "table": { "caption": "表題", "headers": ["列1"], "rows": [["a"]] },
      "mnemonic": "覚え方（任意）"
    }
  ],
  "quiz": [
    { "type": "ox", "q": "...", "a": true, "why": "解説" },
    { "type": "mc", "q": "...", "choices": ["1", "2", "3"], "a": 0, "why": "解説" }
  ]
}
```

`build.py` が三択の選択肢数と正解インデックスを検証するので、壊れたデータはビルド時に落ちる。

## スマホで使う

`index.html` はスマホ幅に最適化してあり、ホーム画面に追加するとアプリのように全画面で開く
（アイコンとメタタグを埋め込み済み）。ただしスマホから開くには、どこかに置いて URL にする必要がある。

### 方法1：Netlify Drop（最短・無料・アカウント不要）

1. PC で <https://app.netlify.com/drop> を開く
2. `index.html` を入れたフォルダ（または `netlify-drop.zip`）をドラッグ&ドロップ
3. 発行された URL をスマホで開く
4. Safari なら「共有 → ホーム画面に追加」、Chrome なら「︙ → ホーム画面に追加」

サインインせずにドロップした場合、サイトは一時パスワードで保護される。
無料アカウントを作ってサイトを claim すれば URL を保持できる。

### 方法2：GitHub Pages

`index.html` がルートにあるので設定は不要。ただし**無料プランでは公開リポジトリが必要**
（private リポジトリを Pages のソースにできるのは GitHub Pro / Team 以上）。
また Pages で公開したサイトは、リポジトリが private でも**サイト自体は公開**になる。

1. リポジトリを public にする
2. Settings → Pages → Source を `Deploy from a branch`、Branch を `main` / `/ (root)`
3. 数分後 `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

### 方法3：Cloudflare Pages ＋ Cloudflare Access

URL を自分だけに限定したい場合。無料枠で、指定したメールアドレス宛のワンタイムコードで
認証をかけられる。Pages にフォルダを直接アップロードし、Access のポリシーで自分のメールを許可する。

### 進捗の保存について

進捗は開いたブラウザごとに保存される（PC とスマホの間では同期しない）。
端末を移すときは「記録」タブの**保存コード**をコピーして、移動先で貼り付けて「復元する」。
iOS でホーム画面に追加した場合、Safari とは別の保存領域になる点に注意。
